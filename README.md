# Guia Preparatório: Vingadores — Doutor Destino

Projeto acadêmico desenvolvido em **React** (Single Page Application) que funciona como um catálogo interativo com os filmes e séries essenciais do Universo Cinematográfico da Marvel (MCU) para assistir antes do lançamento de *Vingadores: Doutor Destino*.

## Funcionalidades

* **Navegação SPA (Single Page Application):** Troca rápida entre as páginas sem recarregar o navegador utilizando `react-router-dom`.
* **Catálogo Organizado:** Divisão entre a *Saga do Infinito*, a *Saga do Multiverso* e filmes clássicos importantes na página inicial.
* **Componentização:** Reutilização do componente `CardFilmes` com passagem dinâmica de dados via `props`.
* **Estilização Modular:** Uso de CSS Modules para isolar o estilo de cada página e componente, além de regras globais no `index.css`.

## Tecnologias Utilizadas

* **React** (`create-react-app`)
* **React Router DOM** (`BrowserRouter`, `Routes`, `Route`, `Link`)
* **CSS Modules** e CSS3
